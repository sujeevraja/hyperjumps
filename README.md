# hyperjumps

A repo to find solutions to the
[Hyperjumps!](https://hyperjumps.quantamagazine.org/) game from
[Quanta magazine](https://www.quantamagazine.org/).


## Usage

- Clone the repository.
- If `pipenv` is not available, install it with `python -m pip install pipenv`.
- Open a terminal in the repository folder and run `pipenv shell`.
- Run a sample trip search with `./find_jumps.py`.
- Test the code with `./test_jumps.py`.
